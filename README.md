# Hours

Tracks the hours you work for each client and turns them into an invoice.

Made with [Lamp](https://lamp.dev), a Mac app that builds apps from a description and changes them as you ask.

## Remix it with Lamp

With Lamp, choose File → Open from GitHub… and paste this repository's address (`https://github.com/lampdotdev/hours`): you get this exact wish, yours to change by asking, with the credits below kept. Don't have Lamp? [Get it](https://lamp.dev).

## Build it yourself

With Apple's Command Line Tools installed (`xcode-select --install`):

```bash
./build.sh
```

The AI inside the app, and anything it does with other apps or devices, goes through Lamp, so those need Lamp open on the same Mac.

Remixed from [Hours](https://github.com/lampdotdev/hours) (a Lamp starter).
